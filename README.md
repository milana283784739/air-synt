# Air Synth — воздушные инструменты

Веб-приложение для ADMIT Hackathon, кейс «Motion: камера вместо джойстика». Играй на пианино, барабанах, гитаре и других инструментах руками перед обычной веб-камерой, без клавиатуры и мыши. Ничего устанавливать не нужно.

**Направление:** свободный вариант, музыкальный инструмент в воздухе.
**Демо:** ссылка на GitHub Pages указана в форме сдачи.

## Устройства
Работает на компьютере и на телефоне (фронтальная камера подключается автоматически, при её отсутствии используется любая доступная). Верстка адаптируется под ширину экрана и учитывает панели браузера на телефоне. Для дуэли на телефоне рекомендуется горизонтальная ориентация — приложение само подсказывает повернуть экран, если места мало.

## Как играть
1. Открой ссылку в Chrome или Edge и нажми режим игры.
2. Разреши доступ к камере. Первый запуск грузит модель 10–20 секунд.
3. Встань так, чтобы обе руки были видны. Свети на руки, чтобы не было темно.
4. Сведи большой и указательный пальцы над клавишей: пока держишь, звучит нота.

## Режимы
- **Сюжет:** 5 глав, в каждой короткая песня из общественного достояния: «Ода к радости» (Бетховен), «Мерцай, звёздочка» (Моцарт), «Мэри и барашек», «Братец Яков», Jingle Bells. Нужную ноту подсвечивает золотой цвет. Главы открываются по очереди за звёзды, прогресс и топ-5 хранятся в браузере.
- **Дуэль:** два игрока перед одной камерой, у каждого своя половина экрана и обе руки (до 4 рук в кадре). Играют одну мелодию, побеждает больший счёт, первому финишировавшему +300.
- **Свободная игра:** обе руки играют независимо, можно брать аккорды.

## Жесты
| Жест | Действие |
|---|---|
| Щипок (большой + указательный) над клавишей, любой рукой | играет ноту, пока держишь; сдвиг вбок меняет ноту |
| Открытая ладонь 1 секунду | смена инструмента |
| Кулак | тишина этой рукой |

Логика жестов написана самостоятельно по 21 точке руки, которые отдаёт MediaPipe. Пороги нормированы на размер ладони (расстояние запястье—основание среднего пальца), поэтому работают на любом расстоянии от камеры. Щипок с гистерезисом, точка нажатия берётся между большим и указательным пальцами, координаты сглажены, кратковременная потеря руки в кадре не обрывает ноту.

## Инструменты (звук и визуал)
Каждый инструмент нарисован на canvas и синтезируется через Web Audio API, готовых аудиофайлов нет.

| Инструмент | Что видно | Как звучит |
|---|---|---|
| Синтезатор | неоновые клавиши | пила с фильтром и эхо |
| Пианино | белые и чёрные клавиши, нажатая утапливается | треугольная волна с затуханием |
| Колокольчик | золотые колокола разного размера, качаются | синус с обертоном |
| 8-бит | зелёные пиксельные блоки | квадратная волна |
| Флейта | серебряная трубка с отверстиями | синус с вибрато |
| Барабаны | установка: бас-бочка, малый, хэт, том 1, том 2, напольный том, крэш, райд | синтез шума и осцилляторов |
| Лёгкая гитара | гриф со струнами, они дрожат | один щипок играет аккорд (C, Dm, Em, F, G, Am, G7, C) с перебором |

## Режим «Ошибка» (твист кейса)
Приложение замечает неправильные и неточные движения и даёт конкретную подсказку в заметном блоке на экране, не чаще раза в 1,5 секунды. Ошибки считаются по типам и показываются на итоговом экране.

| Ситуация | Подсказка |
|---|---|
| Пальцы почти сведены, но не дотягивают | «Сведи большой и указательный пальцы плотнее, чтобы сыграть ноту» |
| Щипок на границе двух клавиш | «Ты между клавишами — сдвинь палец правее/левее к ноте X» |
| Щипок выше зоны клавиш | «Опусти палец ниже — в зону клавиш» |
| Ладонь повёрнута ребром | «Держи ладонь ровнее к камере, иначе жесты не читаются» |
| Рука слишком далеко | «Рука слишком далеко — подойди ближе к камере» |
| Рука выходит за край кадра | «Отодвинься: рука выходит за кадр» |
| Рука дрожит при удержании | «Держи руку спокойнее — нота фальшивит» |
| Низкая уверенность распознавания | «Слишком темно или рука не видна чётко — включи свет» |
| Сыграна не та нота (сюжет, дуэль) | «Нужна нота X, ты сыграл Y. Сдвинь палец правее/левее» |

В дуэли подсказка называет игрока: «Игрок 2: …».

## Запуск
Камера работает только по HTTPS или на localhost, поэтому двойной клик по `index.html` не подходит.
- **Локально:** в папке проекта выполнить `npx serve` и открыть `http://localhost:3000`.
- **Деплой:** GitHub Pages (Settings → Pages → ветка main, корень → Save) или Netlify Drop.

## Если что-то не работает
- Красная надпись на стартовом экране называет причину. Игра сама перебирает варианты модели (видеокарта или процессор, две версии библиотеки), поэтому на слабых компьютерах запуск может занять больше времени.
- Нет камеры: проверь разрешение в настройках браузера (значок замка у адреса) и что камеру не занимает другая программа.
- Плохо ловит руку: включи свет, встань на 0,5–1,5 м от камеры, держи ладонь лицом к камере.

## Технологии
HTML, CSS, JavaScript (один файл `index.html`), MediaPipe Tasks Vision (HandLandmarker, подключён через CDN), Web Audio API, Canvas 2D, localStorage. Бэкенд не нужен.

## Что сделано своими силами
Вся логика: распознавание жестов по точкам руки, режим «Ошибка», игровые режимы, звук всех инструментов, отрисовка инструментов, дуэль. От библиотеки используется только модель поиска точек руки.
